# Создатель ссылок для Obsidian

Автоматический скрипт для добавления wikilinks в хранилище Obsidian. Скрипт анализирует все файлы `.md` в указанной папке и автоматически создает ссылки `[[название]]` при первом упоминании названий других заметок.

## Особенности

- ✅ **Умное обнаружение**: Находит упоминания названий файлов в тексте
- ✅ **Поддержка склонений**: Распознает русские склонения и сохраняет исходное написание
- ✅ **Alias-ссылки**: Использует формат `[[Файл|исходный текст]]` для сохранения склонений
- ✅ **Первое упоминание**: Создает ссылку только при первом вхождении каждого названия
- ✅ **Защита контента**: Не изменяет код, существующие ссылки и URL
- ✅ **Резервное копирование**: Автоматически создает backup перед изменениями
- ✅ **Пробный режим**: Показывает изменения без их применения
- ✅ **Рекурсивный поиск**: Обрабатывает все подпапки
- ✅ **Безопасность**: Множественные проверки и валидация

## Требования

- Python 3.6+
- Стандартные библиотеки Python (os, re, shutil, pathlib, argparse)

## Установка

Просто скачайте файл `obsidian_link_creator.py` в любую папку.

## Использование

### Пробный запуск (рекомендуется сначала)

```bash
python obsidian_link_creator.py content --dry-run
```

Этот режим покажет, какие изменения будут сделаны, но не изменит файлы.

### Применение изменений

```bash
python obsidian_link_creator.py content --apply
```

Этот режим применит изменения к файлам. Автоматически создается резервная копия.

### Применение без резервной копии

```bash
python obsidian_link_creator.py content --apply --no-backup
```

**⚠️ Осторожно**: Используйте только если у вас есть собственная система резервного копирования.

## Примеры

### Базовое использование

```bash
# Пробный запуск для папки content
python obsidian_link_creator.py content

# Применить изменения
python obsidian_link_creator.py content --apply
```

### Для других папок

```bash
# Для папки с заметками в другом месте
python obsidian_link_creator.py "/path/to/my/vault" --apply

# Для подпапки
python obsidian_link_creator.py "content/Общество подменышей" --apply
```

## Как это работает

1. **Сканирование**: Скрипт рекурсивно сканирует указанную папку и находит все файлы `.md`
2. **Генерация вариантов**: Для каждого названия файла создаются возможные склонения
3. **Анализ**: Для каждого файла анализируется содержимое и ищутся упоминания названий и их склонений
4. **Фильтрация**: Исключаются защищенные области (код, существующие ссылки, URL)
5. **Приоритизация**: Обрабатываются более длинные названия первыми для точности
6. **Применение**: Создаются ссылки с сохранением исходного написания:
   - `[[Название]]` - если текст точно совпадает с названием файла
   - `[[Название|исходный текст]]` - если есть различия в регистре или склонении

## Что обрабатывается

- ✅ Обычный текст
- ✅ Заголовки
- ✅ Списки
- ✅ Цитаты

## Что НЕ обрабатывается

- ❌ Блоки кода (\`\`\`код\`\`\`)
- ❌ Инлайн код (\`код\`)
- ❌ Существующие wikilinks ([[ссылка]])
- ❌ Встроенные файлы (![[файл]])
- ❌ URL (http://, https://, www.)

## Примеры обработки склонений

Скрипт умеет распознавать и правильно обрабатывать русские склонения:

### Если есть файл `Подменыши.md`:

- `подменыши` → `[[Подменыши|подменыши]]`
- `подменышей` → `[[Подменыши|подменышей]]`
- `подменышам` → `[[Подменыши|подменышам]]`
- `Подменыши` → `[[Подменыши]]` (точное совпадение)

### Если есть файл `Греза.md`:

- `грезы` → `[[Греза|грезы]]`
- `грёз` → `[[Греза|грёз]]`
- `грезой` → `[[Греза|грезой]]`

### Если есть файл `Дворы.md`:

- `дворов` → `[[Дворы|дворов]]`
- `дворам` → `[[Дворы|дворам]]`
- `двор` → `[[Дворы|двор]]`

Это позволяет сохранить естественность русского текста, при этом создавая правильные ссылки на соответствующие файлы.

## Безопасность

- **Резервные копии**: Автоматически создаются с временной меткой
- **Пробный режим**: По умолчанию показывает изменения без применения
- **Валидация**: Проверка существования файлов и папок
- **Обработка ошибок**: Graceful handling ошибок чтения/записи

## Структура резервных копий

Резервные копии создаются в родительской папке хранилища:

```
parent_folder/
├── content/                    # Ваше хранилище
└── backup_content_20241215_143022/  # Резервная копия
```

## Настройка

В коде скрипта можно изменить следующие параметры:

````python
# Минимальная длина названия для создания ссылки
self.min_title_length = 3

# Дополнительные паттерны для исключения
self.exclude_patterns = [
    r'```[\s\S]*?```',  # Блоки кода
    r'`[^`]+`',         # Инлайн код
    # ... добавьте свои паттерны
]
````

## Устранение проблем

### Скрипт не находит заметки

- Убедитесь, что путь к папке правильный
- Проверьте, что файлы имеют расширение `.md`

### Слишком много/мало ссылок

- Измените `min_title_length` для фильтрации коротких названий
- Добавьте паттерны в `exclude_patterns` для исключения определенного контента

### Ошибки кодировки

- Убедитесь, что файлы сохранены в UTF-8
- Проверьте локальные настройки системы
